# Тест по C# · SOFIA LEBEDEVA & 🐳

Нежный пастельный тест по основам C# с загрузкой вопросов из Google Таблицы. Включает в себя фильтр по темам, таймер, сохранение рекордов и скачивание результатов.

## 🚀 Демо

После публикации на GitHub Pages сайт доступен по адресу:
`https://sfl-11.github.io/test-lebedeva/`

## ✨ Возможности

- 🎨 **Пастельное оформление**: лаванда, мята и персик, округлый шрифт Nunito.
- 🏷️ **Фильтр по темам**: перед стартом можно выбрать конкретную тему (ООП, Циклы, Массивы и т.д.).
- ⏱️ **Таймер на 10 минут**: по истечении времени тест автоматически завершается.
- 📊 **Прогресс-бар**: показывает, сколько вопросов пройдено.
- 🎲 **Случайный порядок**: вопросы и варианты ответов перемешиваются (Фишер–Йетс).
- 🏆 **Лучший результат**: сохраняется в памяти браузера (LocalStorage) для каждой темы.
- 💾 **Скачивание результатов**: можно скачать итог теста в формате `.txt`.
- 📱 **Адаптивность**: отлично выглядит на телефонах и компьютерах.

## 🛠️ Технологии

- **HTML5, CSS3, JavaScript** (Fetch API, LocalStorage)
- **Bootstrap 5** (через CDN)
- **Google Fonts** (Nunito)
- **Google Sheets** (публикация как TSV)
- **GitHub Pages** (хостинг)
